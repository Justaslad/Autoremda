## Past Projects

Reusable component lookup rule:
Whenever I ask for a functionality, section, pattern, or component, you must first check whether it already exists in the Obsidian library under past projects before creating it from scratch.

Before building anything new:
1. Search the library for matching or closely related reusable elements.
2. Use project metadata and component tags to identify relevant past implementations.
3. If a matching component exists, reuse or adapt that code first.
4. Only create a new implementation if no suitable match is found in the library.

Each project entry must contain:

- full code
